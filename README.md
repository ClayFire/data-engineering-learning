# Data Engineering Learning

Este repositorio documenta mi proceso de aprendizaje y práctica hacia el área de **Data Engineering**.

Aquí desarrollo ejercicios y pequeños proyectos enfocados en el trabajo con datos, incluyendo consultas SQL, procesamiento de datos con Python y construcción de pipelines básicos.

## Tecnologías

- SQL
- Python
- PostgreSQL
- ETL Pipelines
- Cloud (BigQuery)

## Contenido del repositorio

El repositorio incluye ejercicios prácticos y mini proyectos relacionados con:

- consultas SQL y análisis de datos
- manipulación y limpieza de datos con Python
- práctica con bases de datos relacionales
- experimentación con pipelines de datos

## Ejercicios SQL

Primer dataset de ventas utilizado para practicar consultas SQL básicas y de análisis.

Consultas realizadas:

- creación de tablas
- inserción de datos
- agregaciones con `GROUP BY`
- ordenamiento de resultados
